# Architecture Decision Records

One file per decision. Numbered, append-only, never rewritten.

When the agent (or a human) wants to know **why** something is the way it
is, this folder is the answer. When the answer is no longer true, write a
new ADR that supersedes the old one.

## Template

Use `0001-template.md` as a starting point. Copy it to the next number
and rename to something memorable: `0007-use-postgres-for-state.md`.
