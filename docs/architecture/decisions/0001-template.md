# 0001 - Template

**Status.** template

**Date.** YYYY-MM-DD

## Context

What is the situation? What constraints, requirements, or pain points led
to this decision being needed? Stick to facts; save opinions for the
"Decision" section.

## Decision

What did we choose? One paragraph. State it as an active sentence:
"We will use X for Y because Z."

## Consequences

What changes because of this decision?

- Positive consequences.
- Negative consequences and trade-offs.
- Follow-up work this implies.

## Alternatives considered

Brief notes on the other options and why they lost. This is what protects
a future reader (or agent) from re-litigating the same debate.
