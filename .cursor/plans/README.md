# Plans

The `/plan` command in `.cursor/commands/plan.md` writes substantive
plans here as `<slug>.md`. They are session-local — gitignored — so a
plan from yesterday does not pollute today's context.

Pick descriptive slugs: `0001-add-auth-middleware.md`,
`0002-migrate-state-to-postgres.md`. Number them if you want order;
slug them if you do not.

Delete a plan when the work is done.
